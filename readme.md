### Objetivo

Criar um script basico que capture voz e transforme para texto usando python.

---

### Dependências

As dependências do projeto estão listadas em `requirements.txt`.

**Instalação:**

```bash
pip install -r requirements.txt
```

**Dependências de desenvolvimento (opcional):**

```bash
pip install -r requirements-dev.txt
```

> **Nota:** o serviço de IA local (porta 1234) deve ser configurado externamente antes de executar o projeto.

---

### Uso

```bash
python main.py
```
